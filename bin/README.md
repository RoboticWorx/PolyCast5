# Compiled Binaries

This folder contains the precompiled PolyCast5 firmware binaries of the latest release.

These files are primarily intended for use with the PolyCast5 [**Firmware Updater**](https://polycast5.com/pages/firmware-updater).

This folder is kept in sync automatically: every `python flash.py` run mirrors the freshly built images here and regenerates `flash_args`, so the committed binaries always match the committed source.

`size_report.txt` is regenerated by the same run: a static size analysis of the build (SRAM/flash/PSRAM usage, image-vs-partition budgets, per-component sizes, as `idf.py size` would report them). Its output is deterministic, so `git log -p bin/size_report.txt` shows exactly how each commit changed the firmware's footprint.

> Note: The flash settings and addresses below must match your PolyCast5 hardware revision / partition layout. `flash_args` is the authoritative, always-current copy of both.

## Flash settings

- `--flash-mode dio --flash-freq 80m --flash-size 16MB`

## Flash map

- `0x2000`   `bootloader.bin`
- `0x10000`  `partition-table.bin`
- `0x4d000`  `ota_data_initial.bin`
- `0x50000`  `PolyCast5.bin`
- `0x850000` `assets.bin`

## Manual flashing (esptool.py)

Replace `COMx` with your serial port (e.g., `COM5` / `/dev/ttyUSB0`):

```bash
esptool.py -p COMx -b 460800 write_flash --flash_mode dio --flash_freq 80m --flash_size 16MB \
  0x2000 bootloader.bin \
  0x10000 partition-table.bin \
  0x4d000 ota_data_initial.bin \
  0x50000 PolyCast5.bin \
  0x850000 assets.bin
```
