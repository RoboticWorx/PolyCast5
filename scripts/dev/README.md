PolyCast5 Development Scripts
====================

Here is a dump of various scripts I used while developing the PolyCast5 for those who are interested.

These hold no practical purpose for an everyday user, but if you're interested in developing PolyCast5 further they may become helpful.

If you find yourself adding a useful improvement, feel free to submit a pull request to the GitHub repository and I'll test it then add it to the main branch if it works.
