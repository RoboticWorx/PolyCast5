PolyCast5 Bluetooth Script Examples
====================

These are some example Bluetooth web portal scripts that you can use in the 'Bluetooth > Keyboard > Add/Edit Script' online web portal for various purposes.

## Naming structure:

Naming structure will follow a few word summary of what the script does then the operating system it has been tested on. This is not to say it wouldn't work on other operating systems, but the keyboard configuration for each is slightly different which may provoke some subtle differences.

For example, the application search bar for Windows would be opened with Win+S, but on Mac it would be Cmd+Space. Something to keep in mind!

## Example structure:

* `Script` - Actual example script code which you can copy and paste to try out if you'd like.
* `Explanation` - Quick summary outlining what the script will do.
* `Steps` - The steps the script will execute broken down into pseudocode for you to follow along with.
