Script:

your@email.comPASSWORD<shift+left><shift+left><shift+left><shift+left><shift+left><shift+left><shift+left><shift+left><cmd+x>

Explanation:

This script will type your username 'your@email.com' into the username section and then write and cut your
password 'PASSWORD' for you to paste (ctrl+v) manually after into the password section.

It is important that you <shift+left> the same number of times as characters in your password. For example,
'PASSWORD' is eight characters long so I write <shift+left> eight times.

Also to note is that people can see you password when running this as it is typed on your screen before the
script cuts it with ctrl+x. This said, I would only use this when you're in a private location.

To reiterate, this script writes out your username and password, then copies and deletes (cuts) the
password part for you to then paste into the password section of the login. The end result is
your username typed out and your password ready to be pasted for fast login.

Steps:
- Types username and password text
- Back-selects the password part
- Cuts out the password (copy + delete)
- Password is now ready to paste
