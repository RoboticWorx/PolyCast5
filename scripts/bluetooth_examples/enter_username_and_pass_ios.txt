Script:

your@email.com<select_prior><cmd+x>PASSWORD

Explanation:

This script types your username 'your@email.com', then the <select_prior> command back-selects it. The
<cmd+x> then cuts the selected username to the clipboard. Finally it types your password 'PASSWORD'.

Run this with the password field selected so others cannot see it. The username is typed, selected and cut to the clipboard,
and then the password is typed directly into the focused field. You then paste (Cmd+V) your username into the username
field manually.

The <select_prior> command saves you from manually counting characters and writing out a <shift+left> for
every character. It selects everything typed before it automatically; you then choose what to do with the
selection, such as cutting it with <cmd+x>, copying it with <cmd+c>, etc.

Steps:
- Types your username
- Back-selects the username with <select_prior>
- Cuts the selected username (copy + delete) to the clipboard with <cmd+x>
- Types your password into the focused field
- Username is now ready to paste into the username field
